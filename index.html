Deploy Automation

Personal automation project

Deploy Automation is a private, single-user tool. When a business brief is submitted through the owner's form, it researches public web sources, writes a consulting-style report, and saves the report as a Word document to the owner's own Google Drive.

Google data use

The app uses Google Drive access only to create report files in a folder chosen by the owner. It does not read, modify, or delete other files, and it is not offered to the public.
